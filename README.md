# crypto-trend-bot

4시간마다 "지금 어디서 회자되는 코인"을 집계해 텔레그램 개인 DM으로 보낸다.

## 소스

| 소스 | 내용 | 가중치 | 자격증명 |
|---|---|---|---|
| **X트렌딩** | X(트위터) 트렌드를 공개 게시하는 trends24.in을 8개 지역에서 읽음. 최근 4시간 스냅샷 전부 | 1.5 | 불필요 |
| **Reddit** | 크립토 서브레딧 7곳의 최근 글 언급량 (RSS) | 1.3 | 불필요 |
| **/biz/** | 4chan /biz/ 카탈로그 최근 스레드 언급량 (댓글수 가중) | 1.0 | 불필요 |
| **검색트렌드** | CoinGecko `/search/trending` 검색 급상승 | 1.0 | 불필요 |
| **거래량** | 24h 거래량 / 시총 회전율 | 0.7 | 불필요 |

각 소스의 순위를 0~1로 정규화한 뒤 가중 합산(Borda) → 상위 20개.
**소셜 실언급(X·Reddit·/biz/)에 더 큰 가중치**를 준다 — 원래 알고 싶은 게
시장 지표가 아니라 "어디서 회자되는가"이기 때문. 실제 언급이 포착된 종목엔 🗣 표시.

소스 하나가 실패하거나 자격증명이 없어도 나머지로 계속 집계한다.

### 왜 Twitter/IG/FB API를 안 쓰나

- **X API**: 검색이 유료(Basic $200/월~). 대신 X 트렌드를 공개 게시하는 집계 사이트를 참조
- **Instagram/Facebook**: 해시태그 트렌드용 공식 API가 없고 스크래핑은 ToS 위반·로그인벽
- **Reddit API**: 2026년에 셀프서비스 키 발급이 폐지됐다. `/prefs/apps`의 create-app 버튼은
  **조용히 아무 일도 안 일어나는 게 정상**이고(계정 설정 문제가 아니다), 지금은 수동 승인을
  거쳐야 하는데 개인 프로젝트는 거의 통과하지 못한다.
  `/r/*/new.json`도 로그인으로 302 리다이렉트된다(실측).
  → **남은 무자격증명 경로는 RSS 뿐**이라 그걸 쓴다

> trends24.in의 robots.txt는 `User-agent: *`에 `Allow: /`와 `Content-Signal: use=reference`를
> 명시한다. 이 봇은 학습에 쓰지 않고 참조만 하며, 정직한 User-Agent로 4시간에 1회만 요청한다.
> (같은 robots.txt가 `ClaudeBot`은 차단하는데, 그건 Anthropic 크롤러 대상이고 이 개인 스크립트와는 별개다.)

## 언급 탐지 — 두 단계 엄격도

티커 매칭은 오탐이 나기 쉬워서 문맥에 따라 기준을 달리한다.

**일반 본문**(Reddit 글, /biz/ 스레드): 캐시태그(`$BTC`) + 맨 티커 + 코인 전체 이름.
단 흔한 영단어는 제외한다 — 안 그러면 `JUST`(JST) `CASH` `REAL` 같은 이름이
평범한 문장에서 무차별로 걸린다.

**X 트렌드 문구**: 훨씬 엄격하게. 트렌드는 `SKY PAYDAY WITH BEAUTILAB` 같은 짧은
광고 문구가 많아 부분매칭하면 화장품 행사가 코인 SKY로 둔갑한다. 그래서
**캐시태그이거나 / 문구 전체가 코인명·심볼과 일치하거나 / 이름이 5자 이상으로
충분히 고유할 때만** 인정한다. 이 규칙이 `Lake Trump`를 TRUMP 코인으로 오인하는 것도 막는다.

**유니버스 밖 캐시태그**: X에 `$FLOP` 같은 소형 코인이 뜨는 게 오히려 조기 신호인데
시총 250위 유니버스만 보면 통째로 놓친다. 그래서 미등록 캐시태그는 CoinGecko 검색으로
해소하되, 레이트리밋 보호를 위해 회당 호출 수를 제한한다.

**거래량 회전율 제외 대상**: 스테이블코인·랩드/스테이킹 파생.
구조적으로 회전율이 높아 화제성과 무관하게 상위를 점거한다
(심볼 목록 + 이름 패턴 + `$1 근처 & 변동 거의 없음` 휴리스틱 3중 필터).

## 직전 회차 대비 변화

스냅샷만 4시간마다 보내면 매번 비슷해 보여서, 뭐가 움직였는지 사람이 두 메시지를
눈으로 대조해야 한다. 그래서 매 회차의 순위를 `state/latest.json`에 남기고
다음 회차가 그걸 기준으로 변화를 표시한다.

- **🆕** 새로 TOP 20에 진입 (상단에 요약도 같이)
- **⬆️9→3 / ⬇️3→9** 3계단 이상 이동. 그 미만의 진동은 표시하지 않는다 —
  다 표시하면 마커가 의미를 잃는다

스냅샷은 **텔레그램 발송에 성공한 뒤에만** 저장한다. 실패했는데 저장하면
다음 회차가 사용자가 본 적 없는 순위와 비교하게 된다.
저장은 워크플로가 리포에 커밋하며(`contents: write` 필요), 푸시가 실패해도
잡을 실패시키지 않고 다음 회차에 다시 시도한다.

## 출력 예시

```
🔥 코인 관심도 트렌드 TOP 20  (08-26 14:01 KST)
🆕 신규 진입 2종: Flop Labs, Pons

1. 🗣 Bitcoin (BTC) #1  -0.3%
    └ Reddit · /biz/ · 검색트렌드
2. ⬆️9→2 🗣 Ethereum (ETH) #2  -1.4%
    └ Reddit · /biz/
3. 🆕 🗣 Flop Labs (FLOP)
    └ X트렌딩 "$FLOP"
```

`#182`는 시총 순위, `0.40x`는 24h 거래량이 시총의 40%, 🗣는 SNS 실언급 포착.
시세 칸이 비어있으면 시총 250위 밖이라 캐시태그로 해소된 종목이다.

## GitHub Secrets

| Secret | 필수 | 설명 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | macro-brief와 동일 봇 재사용 |
| `TELEGRAM_CHAT_ID` | ✅ | 개인 DM용 chat id |
| `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | 선택 | **없어도 RSS로 수집된다.** 있으면 본문 전체·댓글수 가중까지 쓰는 API 경로로 자동 전환 |
| `COINGECKO_API_KEY` | 선택 | 없어도 동작하나 무료 레이트리밋에 더 취약 |

> Reddit 자격증명은 **굳이 만들 필요 없다**. 위에 적었듯 발급 경로 자체가 사실상 막혔고,
> RSS로 이미 수집되고 있다. 혹시 예전에 만들어둔 키가 있다면 넣으면 더 좋아진다
> (구 키는 grandfathering으로 아직 동작한다).

## 알려진 한계

- X 트렌딩에서 크립토가 잡히는 양은 원래 적다(회당 1~3종). 크립토가 일반 트렌드를
  지배하는 일이 드물기 때문 — 잡히면 그만큼 강한 신호로 보면 된다
- **HTML 스크래핑은 깨지기 쉽다.** trends24가 마크업을 바꾸면 파싱이 0건이 되는데,
  그때는 로그에 `파싱 결과 없음(구조 변경 의심)`이 찍힌다. 조용히 틀리진 않는다
- **Reddit RSS는 레이트리밋(429)이 빡빡하다.** 서브레딧마다 따로 요청하면 대부분 막혀서
  `r/A+B+C` 결합 피드 2개로 줄였다. 재미있게도 일반 브라우저 User-Agent가 429를 더 잘 맞고,
  정직하게 신원을 밝힌 UA가 잘 통과한다. 결합 피드는 25건 상한이 있어
  대형/소형 서브레딧을 갈라 담지 않으면 소형 커뮤니티가 통째로 밀려난다
- /biz/는 신호 대비 잡음이 크고 메이저 코인에 쏠린다
- 이 봇이 재는 건 **표본 기반 관심도**지 전수 언급량이 아니다
- 저장소는 **public** — 코드는 공개, 키는 Secrets. Actions 무료 시간 무제한 확보 목적
